# Design system sem página pública

O design system do site permanece interno: tokens, componentes e linguagem de diagrama vivem no código e aparecem nos ensaios, sem uma página `/design-system`. Revertemos a decisão do ADR 0003 porque manter documentação pública paralela ao código custa manutenção constante e desloca o foco editorial para os ensaios, que são o artefato vivo do sistema.
